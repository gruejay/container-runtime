# Steps

The process of building `boxr` is iterative. The point is that you can start from
some basic Go and Linux knowledge and build up piece by piece a deeper understanding
of Go, Linux, and containerization principles. I do not build the entirety of a feature
all at once, but rather took small steps to build iteratively and naturally.
